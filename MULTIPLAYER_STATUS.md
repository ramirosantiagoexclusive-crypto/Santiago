# 🎮 Бесплатный мультиплеер - решение

## Проблема

Публичные MQTT broker'ы часто недоступны или блокируются. Это основная причина сообщения "сервер недоступен".

## Решение

Игра использует **7 публичных MQTT broker'ов** и автоматически переключается между ними:

1. HiveMQ (broker.hivemq.com)
2. Eclipse (mqtt.eclipseprojects.io)
3. Mosquitto (test.mosquitto.org)
4. EMQX (broker.emqx.io)
5. MQTT.HQ (public.mqtthq.com)
6. CesiumTech (mqtt.cesiumtech.com)
7. ThingsBoard (broker.thingsboard.io)

## Как это работает

1. Игра пытается подключиться к первому broker'у
2. Если не получается - автоматически пробует следующий
3. Максимум 21 попытка (7 broker'ов × 3 попытки каждый)
4. Если все broker'ы недоступны - игра работает в одиночном режиме

## Что делать если сервер недоступен

### Вариант 1: Подождите
Публичные broker'ы могут быть временно недоступны. Попробуйте через 5-10 минут.

### Вариант 2: Смените сеть
Некоторые сети (корпоративные, общественные WiFi) блокируют WebSocket соединения. Попробуйте:
- Другой WiFi
- Мобильный интернет
- VPN

### Вариант 3: Бесплатный свой сервер (5 минут)

Если хотите гарантированную работу, можно задеплоить свой сервер бесплатно:

**Railway** (рекомендую):
1. Зарегистрируйтесь на https://railway.app
2. Создайте проект из вашего репозитория
3. Укажите Root Directory: `server`
4. Получите URL и обновите в коде

**Бесплатный тир Railway**: $5 кредитов/месяц (хватит для теста)

### Вариант 4: Локальный тест

Для тестирования на одном компьютере:

```bash
# Терминал 1: запустите сервер
cd server
npm install
npm start

# Терминал 2: запустите клиент
npm run dev
```

Откройте http://localhost:3000 в двух вкладках - увидите мультиплеер в действии.

## Статус подключения

В правом верхнем углу видите индикатор:
- 🟡 **Жёлтый** - подключение...
- 🟢 **Зелёный** - подключено к серверу
- 🔴 **Красный** - сервер недоступен (одиночный режим)

## Открытие консоли браузера

Чтобы увидеть логи подключения:
1. Нажмите F12
2. Перейдите во вкладку "Console"
3. Увидите сообщения вида:
   ```
   [Multiplayer] Попытка 1: wss://broker.hivemq.com:8884/mqtt
   [Multiplayer] ✓ Успешно подключено к wss://broker.hivemq.com:8884/mqtt
   ```

## Итог

Игра работает с **бесплатными публичными серверами**. Если они недоступны - это не ошибка в коде, а временная проблема с серверами. Игра автоматически пытается все доступные broker'ы.

Для гарантированной работы нужен свой сервер (бесплатно на Railway) или подождите пока публичные broker'ы станут доступны.
