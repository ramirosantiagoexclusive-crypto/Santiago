# Изменения для исправления загрузки

## Проблема
Сайт бесконечно загружался потому что мультиплеер подключался сразу при загрузке страницы.

## Решение
Закомментировал автоматическое подключение мультиплеера в `src/App.tsx` (строка 99).

Теперь мультиплеер подключается только после ввода имени игрока.

## Файлы изменены
- `src/App.tsx` - закомментирован `mp.connect()` в строке 99
- `src/game/MultiplayerClient.ts` - добавлена динамическая загрузка PeerJS

## Как проверить
1. Открыть сайт https://ramiros.netlify.app
2. Сайт должен загрузиться за 1-2 секунды
3. Появится окно ввода имени
4. После ввода имени подключится мультиплеер
5. Открыть на другом устройстве - игроки увидят друг друга
