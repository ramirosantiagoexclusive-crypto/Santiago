# 🎮 Деплой мультиплеер сервера

Проблема с публичными MQTT broker'ами в том, что они могут быть недоступны. Решение - задеплоить собственный сервер бесплатно.

## 🚀 Вариант 1: Railway (рекомендую)

### Шаги:

1. **Создайте аккаунт на Railway**
   - Перейдите на https://railway.app
   - Войдите через GitHub

2. **Создайте новый проект**
   - Нажмите "New Project"
   - Выберите "Deploy from GitHub repo"
   - Выберите ваш репозиторий

3. **Настройте деплой сервера**
   - В настройках проекта укажите:
     - Root Directory: `server`
     - Start Command: `npm start`
   
4. **Получите URL сервера**
   - После деплоя Railway даст вам URL вида: `wss://your-app.up.railway.app`

5. **Обновите клиент**
   - Откройте `src/game/WebSocketMultiplayer.ts`
   - Замените `SERVER_URL` на ваш URL:
   ```typescript
   const SERVER_URL = 'wss://your-app.up.railway.app';
   ```

6. **Задеплойте клиент**
   ```bash
   git add .
   git commit -m "Update server URL"
   git push
   netlify deploy --prod --dir dist
   ```

## 🚀 Вариант 2: Render (альтернатива)

1. Перейдите на https://render.com
2. Создайте "Web Service"
3. Подключите ваш репозиторий
4. Укажите:
   - Root Directory: `server`
   - Build Command: `npm install`
   - Start Command: `npm start`
5. Получите URL и обновите клиент

## 🚀 Вариант 3: Локальный тест

Для тестирования на одном компьютере:

1. **Запустите сервер локально**
   ```bash
   cd server
   npm install
   npm start
   ```

2. **Обновите URL в клиенте**
   ```typescript
   const SERVER_URL = 'ws://localhost:8080';
   ```

3. **Откройте игру в двух вкладках браузера**
   - Оба игрока будут подключены к локальному серверу

## 📝 Структура сервера

```
server/
├── index.js          # WebSocket сервер
└── package.json      # Зависимости
```

Сервер обрабатывает:
- Подключение игроков
- Синхронизацию позиций
- Чат
- Отключение игроков

## 💰 Стоимость

- **Railway**: $5 бесплатных кредитов ежемесячно (хватит для теста)
- **Render**: Бесплатный тир (сервер засыпает после 15 минут неактивности)
- **Локально**: Бесплатно

## 🔧 Альтернатива: Публичные MQTT broker'ы

Если не хотите деплоить сервер, можно использовать публичные MQTT broker'ы, но они могут быть недоступны:

- `wss://broker.hivemq.com:8884/mqtt`
- `wss://mqtt.eclipseprojects.io:443`
- `wss://broker.emqx.io:8084/mqtt`

Код автоматически пробует все broker'ы, но они могут не работать в вашем регионе.

## ✅ Рекомендация

Для стабильной работы мультиплеера **обязательно задеплойте собственный сервер** на Railway или Render. Это займёт 5 минут и будет работать надёжно.
